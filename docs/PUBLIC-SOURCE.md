# 公開原始碼與資料邊界

公開庫只提供應用程式、遷移、建置工具、依賴鎖定檔與合成測試程式。原工作目錄的 README、開發對話、Owner 驗收報告、試算表、截圖、資料庫及證據附件不會公開。此發布 clone 與使用中的 ERP 分離；不會將原工作目錄改造成 Git 儲存庫。

.gitignore 阻擋 data、artifacts、backups、conversation-assets、runtime、node_modules、虛擬環境、實際.env、資料庫側車、私鑰及成品封裝。請逐檔審查新增內容；不要使用強制加入去繞過敏感檔排除。

測試中的技術性 Actor 固定識別碼與標記DEMO的合成角色是程式設計內容，不是驗證過的帳號。歷史驗證工具部分要求未公開的本機基準，請先閱讀其保護及前置條件；不要為重播測試而重建 Owner 資料。
